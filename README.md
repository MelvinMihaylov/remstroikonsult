# Remstroikonsult

Marketing site for **Ремстрой Консулт** built with Next.js.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

Set `NEXT_PUBLIC_SITE_URL` to the production site URL so metadata, `robots.txt`, and `sitemap.xml` use the correct domain.
